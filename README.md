# Intelligent Robot Navigation using Q-Learning

## Overview
This project implements an intelligent robot navigation system using Q-Learning Reinforcement Learning. The robot learns the shortest path in a grid-world environment while avoiding obstacles and maximizing rewards.

## Features
- Grid-world simulation
- Q-Learning algorithm
- Manual and AI navigation
- Obstacle avoidance
- Shortest path visualization
- Reward optimization
- Multiple grid sizes

## Technologies Used
- Python
- CustomTkinter
- NumPy
- Matplotlib

## Run the Project

```bash
pip install -r requirements.txt
python main.py
